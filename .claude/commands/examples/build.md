# Build: $ARGUMENTS

Follow the `Workflow` to implement the plan, then `Report` the completed work.

## Workflow

1. Read the plan at `$ARGUMENTS`
2. Think through the plan carefully
3. Implement each step into the codebase

## Report

After completing implementation:
- Summarize the work in a concise bullet point list
- Show files and lines changed: `git diff --stat`
