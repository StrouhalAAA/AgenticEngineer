# Claude Code 2.1.0 Release Notes

**Release Date:** January 7, 2026  
**Hotfix:** 2.1.1 released January 8, 2026

---

## Overview

Version 2.1.0 is the most significant release since 2.0, shipping **1,096 commits** with **109 documented changes**. Key themes: skills hot-reload, agent-scoped hooks, wildcard permissions, and forked context execution.

⚠️ **Security Fix**: OAuth tokens, API keys, and passwords were exposed in debug logs. Upgrade immediately for CI/CD pipelines.

---

## Features (Team Relevance: ⭐⭐⭐ High | ⭐⭐ Medium | ⭐ Low)

### Skills System ⭐⭐⭐

| Feature | Description |
|---------|-------------|
| **Hot-reload** | Skills in `~/.claude/skills` or `.claude/skills` activate immediately without session restart |
| **`context: fork`** | Run skills in isolated context that inherits conversation history |
| **`agent` field** | Specify which agent type executes the skill |
| **`user-invocable: false`** | Hide skill from slash command menu |
| **Slash menu visibility** | Skills now appear in `/` autocomplete by default |
| **Suggestion prioritization** | Recently/frequently used skills ranked higher |
| **YAML-style lists** | Cleaner `allowed-tools` declarations in frontmatter |

### Hooks System ⭐⭐⭐

| Feature | Description |
|---------|-------------|
| **Agent-scoped hooks** | Define PreToolUse, PostToolUse, Stop hooks in agent/skill frontmatter |
| **`once: true`** | Single-execution hooks per session |
| **Prompt/agent hooks from plugins** | Previously only command hooks supported |

### Permissions ⭐⭐⭐

| Feature | Description |
|---------|-------------|
| **Wildcard Bash** | Patterns like `Bash(npm *)`, `Bash(git *)` pre-approve command families |
| **Disable agents** | `Task(AgentName)` syntax in permissions to block specific agents |
| **`--tools` flag** | Restrict available built-in tools in interactive mode |

### MCP Integration ⭐⭐

| Feature | Description |
|---------|-------------|
| **`list_changed` notifications** | Servers dynamically update tools/prompts/resources without reconnection |

### Session Management ⭐⭐

| Feature | Description |
|---------|-------------|
| **`/teleport`** | Resume sessions on different machines |
| **`/remote-env`** | Configure remote execution environments |
| **Unified Ctrl+B** | Backgrounds both bash commands and agents simultaneously |
| **Subagent resilience** | Continue after permission denial, try alternatives |

### Developer Experience ⭐

| Feature | Description |
|---------|-------------|
| **`/plan` shortcut** | Enable plan mode directly from prompt |
| **Slash autocomplete anywhere** | `/` works anywhere in input, not just at start |
| **`language` setting** | Configure response language (e.g., `"japanese"`) |
| **`respectGitignore`** | Per-project @-mention file picker control |
| **Vim motions expansion** | `;`, `,`, `y`/`yy`/`Y`, `p`/`P`, text objects, `>>`, `<<`, `J` |
| **Shift+Enter native** | iTerm2, WezTerm, Ghostty, Kitty without config |
| **Real-time thinking** | Ctrl+O transcript mode shows thinking blocks |
| **`CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS`** | Override default file read token limit |

## Critical Bug Fixes

| Fix | Impact |
|-----|--------|
| **Security: OAuth/API keys in debug logs** | Credentials no longer exposed |
| **Session persistence after 409 errors** | Recovers from transient server errors |
| **Session resume orphaned tool results** | Concurrent execution fixed |
| **OAuth token refresh race conditions** | Stale keychain cache fixed |
| **API context overflow from background tasks** | Truncates to 30K chars with file reference |
| **Files/skills not discovered on resume** | `-c` and `--resume` fixed |
| **PreToolUse hooks allow `updatedInput` with `ask`** | Middleware pattern enabled |
| **Subagents inherit parent model** | Fixed by default |
| **Memory leak in git diff parsing** | Sliced strings no longer retain parents |
| **Write tool permissions** | Now respects system umask instead of hardcoded 0o600 |

## Breaking Changes

### SDK: zod ^4.0.0 Required

```typescript
// String validators moved to root
z.string().email()  →  z.email()
z.string().uuid()   →  z.uuid()

// Record requires two arguments
z.record(z.string())  →  z.record(z.string(), z.string())

// Error access changed
error.errors  →  error.issues
```

Migration: `npx zod-v3-to-v4`

### Windows Managed Settings Path

- **Deprecated:** `C:\ProgramData\ClaudeCode\managed-settings.json`
- **New:** `C:\Program Files\ClaudeCode\managed-settings.json`

### Deprecations

- Removed `#` shortcut for quick memory entry
- Removed permission prompt when entering plan mode
- Atlassian MCP switched to streamable HTTP as default

## Implementation Examples

### Skills Hot-Reload

```bash
# Edit skill while Claude Code is running
vim .claude/skills/my-skill/SKILL.md

# Test immediately - no restart needed
> /my-skill do something
```

### Agent-Scoped Hooks

```yaml
# In skill or agent frontmatter
---
name: secure-builder
hooks:
  PreToolUse:
    - matcher: "Bash"
      hooks:
        - type: command
          command: "./scripts/security-check.sh"
  PostToolUse:
    - matcher: "Edit|Write"
      hooks:
        - type: command
          command: "./scripts/run-linter.sh"
          once: true  # Run only once per session
---
```

### Wildcard Permissions

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git *)",
      "Bash(pytest:*)"
    ],
    "deny": [
      "Bash(npm publish *)",
      "Bash(git push *)"
    ]
  }
}
```

### MCP list_changed

```typescript
// Server notifies Claude Code when tools change
await server.notification({
  method: 'notifications/tools/list_changed',
  params: {}
});
// Claude Code refreshes available capabilities automatically
```
