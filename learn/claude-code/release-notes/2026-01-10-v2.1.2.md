# Claude Code 2.1.2 & 2.1.3 Release Notes

**Release Date:** January 9-10, 2026  
**Versions:** 2.1.2 (Jan 9) | 2.1.3 (Jan 10)

---

## Overview

Version 2.1.2 is a substantial patch release focused on **output preservation**, **security hardening**, and **UX polish**. Version 2.1.3 followed immediately with Agent SDK bump to 0.2.3.

⚠️ **Security Fix**: Command injection vulnerability in bash command processing. Upgrade immediately.

---

## Features (Team Relevance: ⭐⭐⭐ High | ⭐⭐ Medium | ⭐ Low)

### Output Preservation ⭐⭐⭐

| Feature | Description |
|---------|-------------|
| **Large bash outputs to disk** | No more truncation - full output saved with file path reference |
| **Large tool outputs persisted** | Complete output available via file references |

**Why it matters:** SQL queries, build logs, and verbose outputs no longer lose critical information mid-stream.

### Plugin & Agent Control ⭐⭐⭐

| Feature | Description |
|---------|-------------|
| **`FORCE_AUTOUPDATE_PLUGINS`** | Enable plugin updates even when main auto-updater is disabled |
| **`agent_type` in SessionStart** | Hooks now know which agent triggered them via `--agent` flag |
| **Unified `/plugins` view** | Plugins and MCPs grouped by scope (project/user/global) |

### Developer Experience ⭐⭐

| Feature | Description |
|---------|-------------|
| **Shift+Tab in plan mode** | Quickly select "auto-accept edits" option |
| **Image source metadata** | Dragged images include origin path for context-aware responses |
| **Clickable file paths (OSC 8)** | Cmd+Click paths in iTerm, Kitty, WezTerm |
| **winget support** | Windows Package Manager installations with auto-detection |

### Improvements ⭐

| Improvement | Description |
|-------------|-------------|
| **Permission explainer** | No longer flags routine dev workflows (git, npm, tests) as medium risk |
| **Option-as-Meta hint** | Terminal-specific instructions for iTerm2, Kitty, WezTerm |
| **SSH image paste error** | Now suggests `scp` instead of unhelpful clipboard hint |

---

## Critical Bug Fixes

| Fix | Impact |
|-----|--------|
| **🔴 Command injection vulnerability** | Malformed bash input could execute arbitrary commands |
| **Memory leak (tree-sitter)** | WASM memory no longer grows unbounded in long sessions |
| **Binary files in `@include`** | Images/PDFs no longer accidentally loaded into memory |
| **Remote session URL + `/tasks`** | Teleport functionality now works properly |
| **MCP tool names in analytics** | User-specific server configs no longer exposed |
| **"Another installation in progress"** | False positive fixed |
| **Socket files crash** | Defense-in-depth for EOPNOTSUPP errors |

## Breaking Changes

### SDK: zod ^4.0.0 Required (Carried from 2.1.0)

If building custom tools/plugins, ensure zod is updated:

```bash
npx zod-v3-to-v4
```

### Windows Managed Settings Path

| Status | Path |
|--------|------|
| **Deprecated** | `C:\ProgramData\ClaudeCode\managed-settings.json` |
| **New** | `C:\Program Files\ClaudeCode\managed-settings.json` |

## Implementation Examples

### Full Output Preservation

```bash
# Before 2.1.2: Large outputs truncated after ~30K chars
# After 2.1.2: Full output saved to disk, Claude references the file

# Example: Large SQL query results
claude "Run this query against the CRM database and analyze the results"
# → Full result set preserved, even if it's 100K+ characters

# Example: Verbose build logs
claude "Run npm run build and explain any warnings"
# → Complete build output available for analysis
```

### Plugin Auto-Update Control

```bash
# Add to your shell profile (~/.zshrc or ~/.bashrc)
export FORCE_AUTOUPDATE_PLUGINS=true

# Team standardization pattern:
export CLAUDE_AUTO_UPDATE=false          # Disable main auto-updater
export FORCE_AUTOUPDATE_PLUGINS=true     # But keep plugins fresh
```

### Agent-Aware Hooks with `agent_type`

```json
// .claude/settings.json
{
  "hooks": {
    "SessionStart": [
      {
        "command": "bash -c 'echo \"Agent: $AGENT_TYPE\" >> /tmp/claude-sessions.log'",
        "description": "Log which agent started the session"
      }
    ]
  }
}
```

```bash
# The hook receives agent_type when you run:
claude --agent code-reviewer
# → Hook can now behave differently based on which agent is running
```

### Quick Plan Mode

```bash
# Workflow before:
# 1. Enter plan mode → 2. Tab through options → 3. Press Enter

# Workflow after:
# 1. Enter plan mode → 2. Shift+Tab → 3. Press Enter
# Immediately selects "auto-accept edits"
```

```bash
claude --version

```
